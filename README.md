# Seller Panel Bot

Telegram-бот для подписок, рефералов и подключения личных аккаунтов Playerok, Starvell и GGsel.

## Запуск на Windows

1. Распакуйте архив в отдельную папку.
2. Скопируйте `.env.example` в `.env`. Укажите `BOT_TOKEN` своего бота и `ADMIN_ID` владельца.
3. Запустите `start.bat` с Python 3.11 или новее. Скрипт установит зависимости в отдельное окружение `.venv`.
4. Откройте бота и отправьте `/start`. Для настройки отправьте `/admin` с аккаунта владельца.

При обновлении остановите старый процесс. Сохраните резервную копию `data.db` и `.marketplace.key`, затем перенесите их вместе со своим `.env` в папку новой версии. Бот добавит новые поля при первом запуске. Для сохранения доступа к подключённым аккаунтам держите ключ шифрования вместе с резервной копией базы. Архив содержит только пример `.env`.

## Меню и оформление

- Приветствие и каталог отображаются в личном чате как Telegram Widgets со скруглёнными кнопками. В главном меню одна широкая кнопка каталога, под ней профиль и помощь. В каталоге три площадки в одном ряду, ниже широкие «Мои аккаунты» и «Главное меню».
- Подписка и пробный период доступны в профиле. На нижней панели есть «Плагины», «Настройки» и «Меню». Если клиент Telegram не показывает виджеты, команды `/menu` и `/plugins` откроют обычные кнопки. Установка `WIDGET_MENUS=0` в `.env` переключает оформление для всего бота.
- Настройки позволяют включать интеграции и реферальные уведомления. Цвет и форма обычных кнопок зависят от приложения Telegram и его темы.
- В админке есть редакторы приветствия, текстов, названий основных кнопок, их цветов и премиум-эмодзи. Для премиум-эмодзи на кнопках действуют условия Telegram.
- Ссылки «Новости», «Инструкция», «Функционал» и «Поддержка» настраиваются в `Админ-панель → Ссылки`.

## Подключение площадок

Пользователю нужна активная подписка или пробный период и включённый плагин. Владелец бота может проверить интеграции без покупки подписки. Доступно по одному аккаунту каждой площадки на пользователя.

| Площадка | Данные | Проверка |
| --- | --- | --- |
| Playerok | cookie `token` или строка Cookie | Чтение профиля через PlayerokAPI |
| Starvell | cookie `session` или строка Cookie | Чтение профиля через Starvell |
| GGsel | ключ Seller API v2 с правом `api_sellers/v2` | Чтение списка предложений через официальный API |

Создайте ключ GGsel в настройках кабинета продавца. В опубликованной документации Seller API V2 GGsel описан вход по ключу. После ввода бот пытается удалить сообщение с данными подключения. Данные аккаунтов хранятся зашифрованными. В карточке можно повторно проверить или удалить подключение. Интеграция площадок в этой сборке охватывает подключение, проверку и отключение аккаунтов.

## Оплата, подписки и админка

- Настройте сроки и цены подписок, пробный период, реферальный процент и коэффициент Stars в разделе «Тарифы». По умолчанию коэффициент равен 1 XTR за 1 ₽ цены тарифа, после скидки сумма округляется вверх до целого XTR.
- Счета Telegram Stars привязаны к пользователю и сумме. Подписка начисляется после подтверждения Telegram. Для вопросов доступна команда `/paysupport`. Telegram требует Stars для продажи цифрового доступа внутри бота.
- Оплата с внутреннего баланса списывает средства и активирует подписку одной транзакцией. Встроенный баланс можно переводить другому зарегистрированному пользователю.
- Существующие варианты СБП и Crypto Pay остаются доступны при настройке. Кнопка СБП появляется после сохранения реквизитов в админке. Для Crypto Pay задайте `CRYPTO_TOKEN` в `.env`. Для СБП пользователь прикладывает фото или PDF. Администратор получает кнопки «Подтвердить» и «Отклонить». Сохранённые чеки также доступны через `Админ-панель → Чеки СБП`.
- В админке можно искать пользователей, блокировать их, менять подписки и баланс, создавать промокоды, настраивать обязательные каналы, отправлять рассылки и экспортировать список пользователей в CSV. Для проверки обязательной подписки назначьте бота администратором канала.

Документация [Telegram Widgets](https://core.telegram.org/bots/widgets), [Telegram Stars](https://core.telegram.org/bots/payments-stars) и [GGsel Seller API v2](https://seller.ggsel.com/docs/v2/seller-api-v-2).
