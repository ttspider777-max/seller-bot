# Seller Panel Bot (Playerok + Starvell)

Запуск: двойной клик по `start.bat` (или `pip install -r requirements.txt` и `python main.py`).
Токен и ID админа — в `.env` / `config.py`. Админ только `8717087613` — напишите боту `/admin` или нажмите «Админ-панель» в меню.

## Что есть
- Меню: Новости, Инструкция, Функционал (ссылки задаются в админке → 🔗 Ссылки), Бесплатные 7 дней, Профиль, Подписка; нижняя панель — Плагины, Настройки, Меню.
- Профиль: статус/остаток подписки, ID, дата регистрации, покупки, скидка, рефералы, баланс.
- Реф. система (как на скрине): ссылки, статистика, рефералы, транзакции, уведомления, перевод, подробнее, поддержка. Бонус — % с каждой подтверждённой оплаты реферала.
- Подписка: 14 дней / 1 / 3 / 6 мес, промокоды (дни или скидка %), оплата с баланса или по реквизитам. Для оплаты по СБП пользователь прикладывает фото/PDF чека; администратор получает его вместе с кнопками подтверждения/отклонения.
- Админка: статистика, список пользователей (ID, имя, username, подписка), поиск, бан/разбан, выдать/забрать подписку, баланс, промокоды, обязательная подписка (каналы/чаты), редактор ВСЕХ текстов, названий кнопок и премиум-эмодзи на кнопках, приветствие с `{name}`, ссылки, тарифы/реф.%/пробный период/реквизиты, рассылка, экспорт CSV.

## Заметки
- Обязательная подписка: бот должен быть админом в канале/чате.
- Премиум-эмодзи на кнопках: Админка → Кнопки → кнопка → «Премиум-эмодзи» и отправить сообщение с эмодзи. Работает, если у владельца бота есть Telegram Premium. В текстах премиум-эмодзи просто вставляйте в сообщение при редактировании.
- Пользователь с активной подпиской может подключить по одному аккаунту Playerok и Starvell, проверить соединение и отключить аккаунты. Это пока не включает обработку заказов, чатов, автовыдачу, поднятие лотов или мульти-аккаунт.
- В каталоге плагинов доступен переключатель интеграции площадок; автовыдача, автоподнятие, заказы и чаты показаны как функции в разработке. В настройках пользователь может отключить реферальные уведомления и интеграцию площадок.

## Подключение аккаунтов площадок

Пользователь нажимает «Мои площадки» в главном меню и подключает личные аккаунты cookie-сессиями Playerok и Starvell. Бот проверяет профиль только чтением и хранит сессии каждого пользователя отдельно в зашифрованном виде. Для проверки профиля Playerok используется сторонняя неофициальная библиотека; Starvell использует API площадки.

При первом сохранении сессии рядом с базой создаётся `.marketplace.key`. Не удаляйте и не публикуйте этот ключ; сделайте резервную копию вместе с `data.db`. Сессии дают доступ к аккаунтам площадок.
