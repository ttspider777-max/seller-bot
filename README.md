# Seller Panel Bot (Playerok + Starvell)

Запуск: двойной клик по `start.bat` (или `pip install -r requirements.txt` и `python main.py`).
Токен и ID админа — в `.env` / `config.py`. Админ только `8717087613` — напишите боту `/admin` или нажмите «Админ-панель» в меню.

## Что есть
- Меню: Новости, Инструкция, Функционал (ссылки задаются в админке → 🔗 Ссылки), Бесплатные 7 дней, Профиль, Подписка.
- Профиль: статус/остаток подписки, ID, дата регистрации, покупки, скидка, рефералы, баланс.
- Реф. система (как на скрине): ссылки, статистика, рефералы, транзакции, уведомления, перевод, подробнее, поддержка. Бонус — % с каждой подтверждённой оплаты реферала.
- Подписка: 14 дней / 1 / 3 / 6 мес, промокоды (дни или скидка %), оплата с баланса или по реквизитам (админ подтверждает заявку кнопкой).
- Админка: статистика, список пользователей (ID, имя, username, подписка), поиск, бан/разбан, выдать/забрать подписку, баланс, промокоды, обязательная подписка (каналы/чаты), редактор ВСЕХ текстов, названий кнопок и премиум-эмодзи на кнопках, приветствие с `{name}`, ссылки, тарифы/реф.%/пробный период/реквизиты, рассылка, экспорт CSV.

## Заметки
- Обязательная подписка: бот должен быть админом в канале/чате.
- Премиум-эмодзи на кнопках: Админка → Кнопки → кнопка → «Премиум-эмодзи» и отправить сообщение с эмодзи. Работает, если у владельца бота есть Telegram Premium. В текстах премиум-эмодзи просто вставляйте в сообщение при редактировании.
- Сами функции Playerok/Starvell (авто-поднятие, мульти-аккаунт и т.д.) в этом боте пока описаны как витрина; интеграции с маркетплейсами не реализованы.

## Подключение аккаунтов площадок

В `.env` можно локально задать `PLAYEROK_COOKIE` и `STARVELL_SESSION`. Для Playerok укажите значение cookie `token` или полную строку Cookie из браузера; полная строка разбирается локально, библиотеке передаётся только `token`. Старый `PLAYEROK_TOKEN` тоже поддерживается для совместимости. В админ-панели пункт «Подключение площадок» проверяет авторизацию чтением профиля; он не меняет данные на площадках. Playerok использует стороннюю неофициальную библиотеку. Starvell подключается через веб-API площадки. Оба секрета дают доступ к аккаунту: храните `.env` приватно и не пересылайте его.

Проверка подключения не включает авто-поднятие, автовыдачу, обработку заказов/чатов или мульти-аккаунт: этих обработчиков в исходном проекте нет, их нужно реализовывать отдельно поверх API площадок.
